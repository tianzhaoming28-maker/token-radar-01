Launch Radar: a working token launch radar built from the competition snapshot alone. Every protocol that records no token is priced the way the market already prices its launched peers — its TVL times its own category's median market-cap-to-TVL multiple, with each peer's ratio winsorized so one outlier cannot set a category's price, adjusted for seven-day growth and for how long it has run with no token — then ranked by that implied value. The board carries the whole 40-protocol watchlist plus every early protocol below the $50M floor that the same records can price (198 rows). Each row's detail view shows the arithmetic step by step, the launched peers the price leans on, and a seven-step farm plan with a stated cost and time per step; the page is sortable and filterable, and a model sandbox re-ranks the board live under different weights so a reader can see which rows are robust. Screenshots of the board, one detail view and one filtered view are captured from this dashboard and ship in the run output; in this repository they travel as base64 in screenshots-data.ts (regenerated by pack-screenshots.mjs) so every committed file stays text.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```

Point `--input` at a copy of the competition snapshot (the grader mounts it at /input/snapshot.json and the program writes to /output). The run is offline and deterministic: it writes board.json, data.js, the dashboard under dashboard/, the captures under screenshots/ and dossier.json.
